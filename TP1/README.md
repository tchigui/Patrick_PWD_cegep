# TP1 — Mes 12 films préférés

Projet du cours **Web dynamique** (Cégep).  
Objectifs respectés :
- Grille **CSS Grid** en 4 zones : header, menu gauche, contenu, footer
- 12 films en **tuiles** (Flexbox)
- **Spritesheet unique** (icônes + affiches) pour réduire les requêtes HTTP
- **SASS** → CSS **minifié**
- **Responsive** (≤ 50rem) :
  - Menu gauche masqué
  - Affiches plus petites
  - Titre + lien masqués (l’affiche reste cliquable)
- **Accessibilité** : skip-link, focus visible, contrastes améliorés
- **Git** : ≥ 15 commits explicatifs
